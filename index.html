Settings

Cartabase runs entirely on this device — nothing here is sent anywhere unless you turn on the optional vision provider below.

Storage

Vehicle records and photos are stored in this browser's local database (IndexedDB). Clearing your browser's site data for this app, or uninstalling it, will delete everything.

Optional: cloud brand/model detection

The built-in offline detector only reads license plates and color reliably — it honestly can't tell a Toyota from a Honda from pixels alone. Turning this on sends captured photos to an OpenAI-compatible vision API for brand/model/type recognition. Your API key is stored in this browser's local storage and sent directly from your device — there's no server to keep it hidden, unlike a typical app. Only enable this if you're comfortable with that trade-off.
